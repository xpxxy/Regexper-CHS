## 安装与构建

包管理器沿用原项目的 `yarn`
``` bash
yarn install
```
启动项目：
``` bash
yarn start
```
项目将启动在端口 8080 上

其他命令：  

生成文档（待修复）：
``` bash
yarn docs
```
打包：
``` bash
yarn build
```
测试：
``` bash
yarn build
```
